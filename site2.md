# Техническое задание

## Проект

Создать персональный сайт инженерной лаборатории **Rockzo**.

Это не лендинг, не резюме и не классическое портфолио.

Сайт должен производить впечатление инженерного журнала, где представлены исследования, разработки и завершённые решения.

Главная задача сайта — показать инженерный подход автора через реальные проекты.

После просмотра посетитель должен понять:

> Здесь умеют разбираться в сложных технических системах, превращать идеи в архитектуру и доводить их до работающих решений.

---

# Что такое Rockzo

Rockzo — независимая инженерная лаборатория.

Лаборатория объединяет исследования, программные продукты, аппаратные разработки и инженерные эксперименты.

Главная ценность — не технологии, а умение работать со сложными системами.

# Архитектура

Максимально простая.

```
/
    index.html

        variables.css

        animations.css

    js/
        app.js
        observer.js

    assets/
        ...

    data/
        site.json
```

Весь контент должен храниться отдельно.

Не захардкоживать тексты в HTML.

# Источник данных

Все проекты, исследования, ссылки, контакты и тексты должны загружаться из JSON.

Например

```
data/site.json
```

Это позволит обновлять сайт без изменения HTML.

# Масштабируемость

Архитектура должна предусматривать дальнейшее развитие.

В перспективе сайт станет фронтендом для системы LOOM.

Поэтому:

- контент должен быть отделён от представления;
- структура должна легко расширяться;
- компоненты должны быть независимыми;
- новые разделы должны добавляться без переработки существующего кода.

При этом текущая версия должна оставаться полностью статической и совместимой с GitHub Pages.
